== Hallazgos al seguir el README
1. El README pedía 'npm install'; para una instalación reproducible se usa 'npm ci' (respeta package-lock.json). Corregido en el README.
2. El README no mencionaba SEED_ADOPTANTE2_PASSWORD, SEGUIMIENTO_* ni las migraciones numeradas (database/migraciones, npm run db:migrar). Corregido en el README.
3. Defecto: con los valores EJEMPLO_... de .env.example la instalación se completaba igual (contraseñas demo conocidas). Se corrigió en database/instalar.js; verificación:
Error al instalar la base de datos: La variable SEED_ADMIN_PASSWORD todavía tiene el valor de ejemplo de .env.example. Cámbiala por una contraseña propia.
4. npm ci informa 20 vulnerabilidades bajas o moderadas, todas en dependencias de desarrollo (jest, glob, minimatch); "npm audit --omit=dev" da 0 vulnerabilidades en producción. Queda como riesgo residual.
